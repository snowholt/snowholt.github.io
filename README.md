# snowholt.github.io

Personal portfolio — production work in healthcare AI, security, edtech and real-time
voice, alongside open-source projects in signal processing, agents and computer vision.

Static HTML, CSS and a small vanilla script. No build step, no framework.

- `index.html` — all content
- `styles.css` — design tokens and layout
- `app.js` — theme toggle and section highlighting
- `gitprofile.md` — source for the github.com/snowholt/snowholt profile README

Live at [snowholt.github.io](https://snowholt.github.io/).
